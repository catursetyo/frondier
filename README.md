# frondier

Personal dotfiles for **Fedora 43** on the machine `fedorawr`.
Desktop session: **niri + Noctalia** (migrated from Hyprland/JaKooLit on 2026-10-18 —
see the git history for the full journey).

## Architecture

Everything is linked into `$HOME` via symlinks: `~/.config/<app> -> repo/.config/<app>`.
Hyprland caches its config at startup, but niri hot-reloads — edit and save, done.

Three moving parts:

1. **niri** — scrollable-tiling compositor. Its config (`~/.config/niri/config.kdl`) is
   **generated**: the source of truth is the Noctalia template
   (`.config/noctalia/templates/niri-config.kdl`). Edit the template, then render:
   ```bash
   noctalia theme <wallpaper-image> -r "$HOME/.config/noctalia/templates/niri-config.kdl:$HOME/.config/niri/config.kdl"
   ```
2. **Noctalia** — the shell (bar, launcher, control center, notifications, wallpaper,
   lock screen, clipboard panel). Config: plain TOML in `.config/noctalia/*.toml`,
   hot-reloaded. Palette is derived from the wallpaper (`theme.source = "wallpaper"`),
   so the whole look follows every wallpaper change.
3. **keyd** — system-level remap: a Super **tap** emits ScrollLock (bound to the app
   launcher in niri), a **hold** stays a normal Super. Config archived in `system/keyd/`.

## Structure

```
frondier/
├── README.md            # this file
├── UPSTREAM.md          # original Hyprlust README (upstream attribution)
├── install.sh           # symlink installer (safe to run repeatedly)
├── .config/             # application configs (symlinked into ~/.config)
│   ├── niri/            #   compositor config (GENERATED by the Noctalia template — do not edit)
│   ├── noctalia/        #   shell config + templates/ (the niri config template lives here)
│   ├── scripts → ../scripts
│   ├── kitty/           #   kitty.conf (opacity 0.65, no decorations)
│   ├── wlogout/ gtk-*/ qt5ct/ qt6ct/ Kvantum/   # session menu, theming & toolkits
│   ├── nvim/ btop/ fastfetch/ mpv/ newsboat/ zathura/ yazi/ ...
│   ├── matugen/ wallust/ #   color generators (wallust feeds kitty/zathura/rmpc colors)
│   ├── spicetify/ streamrip/ rmpc/ mpDris2/ mpd/ # media
│   ├── Seanime/ smassh/ sptlrx/ swappy/ trakt-scrobbler/ Upscayl/ lobster-rs/ yt-x/ ...
│   └── starship.toml    # prompt
├── scripts/             # compositor-neutral helper scripts (wlogout)
├── system/
│   └── keyd/            # /etc/keyd/default.conf (Super-tap → ScrollLock remap)
├── .zshrc               # shell (sources plugins from .zsh/)
├── .zsh/                # zsh-autosuggestions, zsh-syntax-highlighting, zsh-completions
└── .themes/             # GTK themes (adw-gtk3, Colloid-Dark, Graphite-Dark)
```

## Dependencies

| Package | Source | Role |
|---|---|---|
| `niri` 26.04+ | Fedora updates | compositor |
| `noctalia-shell-v5` | copr `pm4rcin/Hyprland` (fc43 build) or official repo (F44+) | desktop shell |
| `keyd` | copr `alternateved/keyd` | Super-tap remap (`/etc/keyd/default.conf`) |
| `hyprpolkitagent` | Fedora repos | polkit auth dialogs (name says hypr, works everywhere) |
| `wallust` | Fedora repos | kitty/zathura/rmpc colors (run manually) |

Fonts: **Inter** and a **Nerd Font**.

Session-level plumbing (env import, portals, XDG autostart) is handled by
`niri-session` + the packaged `niri-portals.conf` — nothing to configure.

## Usage

```bash
git clone <this-repo-url> ~/programs/linux/frondier   # any location works
cd ~/programs/linux/frondier
./install.sh
# niri hot-reloads; for a clean start, re-login
```

`install.sh` never overwrites existing real files/directories — those are reported as `SKIP`.
